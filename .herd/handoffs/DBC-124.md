### DBC-124 - Linear API Integration
**New Files**:
- `.herd/mcp/src/herd_mcp/linear_client.py`: GraphQL API client using urllib (no new dependencies)
- `.herd/mcp/tests/test_linear_client.py`: Comprehensive test suite (24 tests)

**Modified Files**:
- `.herd/mcp/src/herd_mcp/__init__.py`: Added linear_client to exports
- `.herd/mcp/src/herd_mcp/tools/assign.py`: Added auto-registration and Linear sync
- `.herd/mcp/src/herd_mcp/tools/transition.py`: Added Linear state sync
- `.herd/mcp/tests/test_assign.py`: Added 5 new tests for Linear integration

**Key Features**:
1. **Auto-registration**: When assigning a ticket that doesn't exist in DuckDB but looks like a Linear ID (e.g., DBC-120), fetch from Linear and auto-insert
2. **Assignment sync**: After assigning in DuckDB, update Linear to "Assigned" state
3. **Transition sync**: Map internal statuses to Linear state UUIDs and sync on transition
4. **Graceful degradation**: Linear sync failures don't prevent DuckDB operations (DuckDB is primary)
5. **No new dependencies**: Uses stdlib `urllib.request` (same pattern as tools/log.py)
